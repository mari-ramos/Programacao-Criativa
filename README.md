# Programacao-Criativa

Este projeto, desenvolvido como trabalho final da disciplina “Tópicos Especiais em Sistemas Digitais – Programação Criativa”, é uma releitura interativa do clássico Pong, combinando elementos do Breakout, criada em p5.js. O objetivo vai além da competição tradicional: o jogo transforma cada partida em uma experiência audiovisual dinâmica, na qual música, cores e obstáculos reativos influenciam diretamente a jogabilidade.

Os jogadores devem não apenas marcar pontos, mas sobreviver a um ambiente que reage ao áudio, enquanto a dificuldade e os efeitos visuais evoluem com o tempo. O projeto integra conceitos de física vetorial, colisão de objetos, sistemas de partículas e análise de áudio em tempo real, assuntos discutidos, apresentados ou pelo menos citados nos encontros semais proporcionados pela disciplina.
